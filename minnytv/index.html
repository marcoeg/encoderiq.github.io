MinnyTV YouTube Publisher

MinnyTV YouTube Publisher is an internal, first-party publishing application used exclusively by MinnyTV to upload MinnyTV-produced video content to the MinnyTV YouTube channel.

The application uses the YouTube Data API as part of MinnyTV's internal video production and publishing workflow. It is not offered to third-party users, creators, or YouTube channels.

Access to the MinnyTV YouTube channel is authorized by an authorized MinnyTV administrator through Google OAuth 2.0.

YouTube integration

The application uses YouTube API Services for the purpose of uploading and publishing MinnyTV-owned video content and associated metadata.
